# 2. 档案与安全限制

> 本章仅搬运已拍设计，不授权实现；验收标准均为待实现验证。

## 本章已拍结论

- 正式档案是长期档案事实的唯一来源（训练目标、训练经验、器械与时间条件、动作限制、身体状态与红旗症状）；确认前任何草稿不得修改正式档案，拟议变更仅保存在草稿补丁中。
- 动作限制分两种粒度：具体动作与动作模式（如深蹲、髋铰链、水平推）；普通动作限制经用户确认后长期保留，训练计划不得包含已确认限制覆盖的动作。
- 红旗症状独立阻断常规训练处方：出现红旗症状时不生成常规训练处方，建议线下专业评估；红旗阻断不能由 Agent 自行解除，也不能因计划修订成功而自动解除。
- Agent 不诊断具体疾病，不自动新增或解除永久禁忌；限制的增删只能由用户经草稿确认。
- 长期条件与当次条件分离：“今天只能用哑铃”只作为当次训练条件，不写入长期档案。

## 责任边界

负责：

- 训练目标、经验、器械、时间条件等档案事实的承载与变更边界
- `user_profile` 档案存储职责：单用户档案 JSON + `context_version`，作为统一业务版本与乐观锁基座（PLAN.md「业务表设计」）
- 动作限制与红旗阻断规则
- 拟议档案变更的语义边界（补丁保存在草稿中，确认后才写入正式档案）

不负责：

- 医学诊断、康复处方、自动永久禁忌（PRD §6 首版边界）
- Agent 自行解除限制
- 草稿确认流程、事务编排与幂等（第 1 章）
- 按最新限制对计划的使用时复核与阻断执行（第 4 章）

## 业务规则

### 2.1 建档与档案事实

- 建档通过对话进行，不提供独立建档表单；信息缺失时继续询问，不自行补造（PRD §5.2；交互与草稿机制见第 1 章）。
- 档案承载的事实类别：训练目标、训练经验、每周训练频率与单次可用时长（时间条件）、可用器械、已知动作限制、当前身体状态与红旗症状（v1「业务模块职责」；PRD §5.2）。
- 普通动作限制经用户确认后长期保留（PRD §5.2）。
- 档案页面只读，查看为主；档案变更只能经对话草稿确认（v1「业务交互与确认边界」；见第 1 章 1.2）。

### 2.2 动作限制

- 限制可以针对具体动作，也可以针对动作模式（如深蹲、髋铰链、水平推）（PRD §5.7）。
- 训练计划不得包含已确认限制覆盖的动作（PRD §5.7）。
- 动作限制通过对话增删，必须再次确认，不能在页面直接静默删除（v1「业务交互与确认边界」）。

### 2.3 红旗阻断

- 红旗症状包括胸部异常不适、晕厥、异常气短、锐痛、麻木、放射痛等；出现时不生成常规训练处方，建议线下专业评估（PRD §5.2）。
- 红旗阻断独立于计划修订与接回流程：不能因计划修订成功而自动解除；接回判定同样无权解除红旗阻断（v1「当前计划的使用时安全复核」；PRD §5.12）。
- 红旗阻断不妨碍历史查看或记录用户实际已发生的训练；事实记录不等于推荐执行（v1「当前计划的使用时安全复核」）。
- 当次状态调整为红旗症状时，不生成常规训练处方，建议线下专业评估；红旗阻断不能由 Agent 自行解除（PRD §5.5 状态表；状态调整流程见第 4 章）。

### 2.4 拟议档案变更

- 拟议档案变更（如“以后只能用哑铃”）保存在计划草稿的 `proposed_profile_patch_json` 中，仅供该草稿的计划调整与校验使用，不能被当成已确认的长期事实（v1「受限组合计划草稿」；事务与流程见第 1 章 1.5）。
- 补丁校验与按补丁后条件校验计划在确认事务内执行，不能只按旧条件校验（v1「草稿生命周期与业务事务」；见第 1 章 1.4）。
- “今天只能用哑铃”等当次条件只作为当次训练条件处理，不写入拟议档案补丁，也不修改长期档案（v1「受限组合计划草稿」）。

## 跨模块约束

- 档案与限制变更走第 1 章草稿确认、版本检查与原子事务；`user_profile.context_version` 作为统一业务版本与乐观锁基座，载体归本章，统一业务版本语义见第 1 章 1.4。
- 限制确认生效后，使用当前计划提供训练指导时按最新限制复核整份计划，冲突时阻断训练指导；该复核机制归第 4 章（v1「已生效计划与新限制冲突」）。
- 动作不可用、器械缺失或用户拒绝某动作时的替代建议属于计划与训练指导流程，替换结果必须再次经用户确认，归第 4 章（PRD §5.7；v1「业务模块职责」注记）。
- 红旗阻断优先于计划指导、状态调整与接回流程（第 4 章）。

## 验收标准（待实现验证）

1. 用户确认含普通动作限制的档案草稿后，该限制长期保留；其后生成或修订的计划不得包含该限制覆盖的动作（PRD §5.2、§5.7）。当前计划与新增限制冲突时的训练指导阻断，按第 4 章使用时安全复核机制整份阻断并验收。
2. 用户报告红旗症状后，系统不生成常规训练处方并建议线下专业评估；Agent 不自动新增或解除永久禁忌，不自行解除红旗阻断（PRD §5.2、§5.5）。
