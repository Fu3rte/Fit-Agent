## 业务规则

### 10.1 发布形态与访问范围

- 以 Python 项目形式发布：用户安装 Python 与项目依赖后按文档启动；发布产物包含构建好的前端，运行时不需要 Node.js。
- 前端首版使用 Vite：开发时使用 Vite 开发服务器，生产构建产物由 FastAPI 静态托管；具体目录结构属于实现细节。
- 不采用独立可执行程序：不制作 exe 或其他桌面程序，保持可安装、可启动、可演示的本机 Web 产品交付。
- 仅允许在本机部署并由本机浏览器访问：服务只监听回环地址，不提供局域网或公网访问，不建设账号系统；保留基本的 Host/Origin 校验。
- 此部署限制针对 Fit-Agent Web 服务，不改变已确认的云端模型调用能力。

### 10.2 数据目录与备份约束

- 使用 `platformdirs` 解析跨平台用户数据目录；Windows 数据库路径为 `%LOCALAPPDATA%\Fit-Agent\app.db`；数据文件继承操作系统用户目录 ACL，不自建跨平台权限系统。
- Web 提供“打开数据目录”按钮，但不提供数据库在线下载。
- 服务停止后才允许用户手动复制或删除数据目录；运行中备份必须使用 SQLite Backup API。

### 10.3 Provider 凭据与密钥边界

- Provider 配置和明文 API Key 与会话、业务数据保存在同一个 SQLite 数据库；本地单用户场景接受依赖用户目录 ACL，拥有相同操作系统用户权限或数据库副本者可以读取 Key。
- Web 设置页支持录入、替换和显式删除 API Key。
- Provider 查询接口默认只返回 `has_api_key`；仅在确有识别需求时才返回掩码。
- 完整 Key 不得进入响应、日志、Trace、`run_events` 或异常详情。
- 模型调用时按需从 Provider 配置读取 Key，用完不得持久化到其他表。
- 真实验证凭据边界（仅适用于真实验证进程，产品运行时按上一条从同库读取 Key）：真实调用前只检查环境变量是否存在，不显示值；API Key 仅经环境变量传入调用进程，不从会话日志提取密钥，不将密钥写入源码、命令行参数、临时文件、日志或报告。`.env` 中已配置 API Key 不代表执行进程已获得环境变量。

### 10.4 费用护栏的归属

- spike 专属费用护栏（max_tokens≤256、重试禁用、串行、$5 自动停与 $10 绝对硬顶、持久账本）仅属 spike 授权，归第 12 章历史归档；不自动用作生产或测评配置（测评侧见第 9 章 9.6）。
- 测评费用预算（本轮累计人民币 20 元硬上限与持久账本规则）归第 9 章。
- 生产侧 Harness 执行与费用预算原则（所有额外尝试纳入统一执行与费用预算）归第 8 章。Stage 4 本批联调累计 10 美元、请求前预留、真实 usage 结算、未知 usage 保守扣账继续与跨重启累计已于 2026-09-12 拍板；不含 Stage 5 测评，不作为产品长期默认预算。当前仅授权文档同步，不授权实现或立即调用；操作正本见第 8 章「Stage 4 联调费用护栏」。
- 本章仅登记费用护栏的归属与跨章边界，不持有护栏决策本体，不新增费用护栏决策。

## 验收标准（待实现验证）

1. 服务只监听回环地址，局域网或公网设备无法访问；Host/Origin 校验生效（v1 L26）。
2. 发布产物按 Python 项目形式安装启动，运行时不需要 Node.js（v1 L21）；Windows 成品验收平台与按清单实测归第 9 章（v1 L22）。
3. 数据库文件位于平台用户数据目录（Windows 为 `%LOCALAPPDATA%\Fit-Agent\app.db`），权限继承用户目录 ACL（v1 L42）。
4. Provider 查询接口默认仅返回 `has_api_key`，仅在确有识别需求时才返回掩码；设置页录入的完整 Key 不出现在查询响应、日志、Trace、`run_events` 或异常详情（v1 L322–324）。
5. 服务停止前无法以复制目录方式备份数据库，运行中备份经由 SQLite Backup API 完成（v1 L327）。
6. 真实验证进程仅经环境变量获得密钥；产品运行时按需从同库 Provider 配置读取密钥；不从会话日志提取密钥，不将密钥写入源码、命令行参数、临时文件、日志或报告（PLAN.md 2026-09-08 收窄前「环境凭据现状」L19（历史来源）；现承载见第 10 章 10.3）。
