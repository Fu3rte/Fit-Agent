# 6. 统计与复盘数据

> 本章仅搬运已拍设计，不授权实现；验收标准均为待实现验证。本章承接第 5 章移交的统计侧内容（v1 L67、L131、L203–204）。

## 本章已拍结论

| 决策 | 选项 | 选了 | 为什么 |
|---|---|---|---|
| 训练完成率 | A 按训练次数 / B 按工作组 | A | 区分完成一次训练与组级处方执行，不用多做的组抵消漏练 |
| 工作组展示 | 三桶组数 / 额外计算合格组百分比 | 三桶组数，名称为“符合处方目标的工作组” | 表达执行情况，不暗示其他组无效；首版不额外展示百分比 |
| 缺失判定信息 | 当作未符合 / 单列待补全 / 忽略缺失要求 | 单列待补全，工作台与复盘共用状态 | 不编造事实，不让两个界面各用一套词汇或判定结果 |
| 周与版本归属 | 全局自然周 / 按计划版本的 Wn | 完成率及训练复盘按 Wn，新版本独立统计 | 不迁移、不合并旧版执行度，仅做统计分段，不建设复杂周期系统 |
| PR 来源 | A 所有带数字的组 / B 正式有效且可比较的工作组 | B | 草稿和待补全训练记录不污染 PR，补全并确认正式有效后自动参与 |
| 次数区间边界 | A 单值精确匹配 / B 隐含容差 / C 处方显式区间 | C，包含端点，无隐藏容差；单值为同值上下界 | 页面处方与确定性判定一致，不能事后改标准 |
| 三桶判定顺序 | A 缺字段优先 / B 已知未满足优先 | B | 已知未满足即可判为未符合，否则必要信息缺失为待补全 |
| 当前统计与复盘依据 | A 当前统计现算，复盘保存当时数值和来源修订 / B 仅保存来源修订引用 | A（2026-09-07） | 当前统计不以持久化结果为事实源；旧复盘保留生成时依据，解释历史结论，快照不参与当前统计 |
| 更正后的统计与复盘 | 历史数值重算；旧复盘标记依据已变更，不静默重写 | 已确认 | 数值反映最新有效事实，旧解释保留其历史语境 |
| 辅助组 PR | A 排除普通 PR / B 辅助 PR / C 拆算独立次数 | A | 保留真实工作组但不混入独立完成纪录，不建设辅助 PR 或拆算 |

## 业务规则

### 6.1 完成率与计划周

- 口径：同一计划版本、同一 Wn 内已完成的计划训练次数 ÷ 截至当前已到训练日期的应训练次数（v1 L133–144）。
- 分母来自应训练日程，而非已有打卡；不能只从已有打卡推算分母，必须能列出没有打卡的应训练安排（v1 L133–144；PLAN.md 2026-09-08 收窄前「业务表设计」L228（历史来源）；现承载见第 6 章）。
- 休息日不进分母，未来未到日期的安排不进分母，漏练保留；整周安排次数可另外展示（v1 L133–144）。
- 分子：用户在正式记录中明确确认本次训练已完成，且至少包含一个实际工作组，才计入完成次数；完成不等于所有工作组符合处方目标（v1 L133–144）。
- 同一次安排最多贡献一次完成；无安排训练、额外训练及同次多次反馈不增加计划完成次数（v1 L186–195、L201；PLAN.md 2026-09-08 收窄前「业务表设计」L228（历史来源）；现承载见第 6 章）。
- 分母为零显示“暂无”，不是 0% 或 100%；新版本无应训练次数也不显示成 0%（v1 L133–144）。
- 历史不倒改：安排变更不重算已锁定历史，漏练不因后续变更消失；日程与当次处方的锁定归第 4 章（v1 L120、L133–144）。
- 事后真正补练作为额外训练展示，原漏练及分母不变；当天确实完成、后来才补录属于历史事实更正，不等同于事后补练（v1 L133–144）。
- W1 为计划版本开始日期起连续 7 天，W2 为随后 7 天，以此类推；完成率与训练复盘按计划周 Wn，不使用全局“周一至周日”口径；步数、体重的自然周口径不构成新增首版功能的承诺（v1 L133–144）。
- 新计划版本开启独立统计区间，不继承旧计数；旧版本连同历史完成率归档，不迁移、不合并，但仍允许真实记录更正并重算；此处仅为统计分段，不建设复杂周期系统（v1 L133–144）。
- 安排变更对历史的影响：未来可调整、历史不倒改（v1 L120）。

### 6.2 组级判定（三桶）

- 展示名称统一为“符合处方目标的工作组”，说明实际表现是否符合当次处方，并为复盘、后续调整提供证据；不代表动作技术、安全性或训练效果合格，不能单凭组数自动加重（v1 L145–155；PRD §5.8）。
- 工作台三桶与复盘沉淀共用“符合目标／未符合／待补全”三种组级状态及同一确定性计算结果，一一对应；原“信息不足”统一称为“待补全”，不另设同义状态；首版展示组数，不额外展示合格组百分比（v1 L145–155；PRD §5.8）。
- 判定顺序：存在已知未满足的目标则为“未符合”，可同时提示缺失字段；否则缺必要判定信息为“待补全”；全部目标满足才为“符合目标”。不能只因缺失信息判为未符合（v1 L127、L145–155）。
- 判定基准以当次安排快照为准，不以计划版本直接判定；无对照安排时不判定（v1 L94；PRD §5.8）。
- 无对照安排、额外组或不适用次数判定的训练不进入三桶，单独展示实际表现，不以待补全为由要求补造目标（v1 L145–155）。
- 次数判定：判定只看次数；次数落在已确认处方的显式接受区间内（含端点）为“符合目标”，低于下限或超过上界为“未符合”；没有隐藏容差，单值按同值上下界处理，不能在复盘时改写标准；超过上界不属于符合目标，但不代表该组无效（v1 L126、L145–155）。
- 组级处方判定与整条记录的正式有效性分开：待补全记录中的工作组仍进入组级判定，缺次数记为“待补全”；整条记录处于草稿或待补全时不参与 PR。共用“待补全”用语不意味着把不同对象的状态混成一个状态（v1 L145–155、L204）。
- Agent 复盘报告是否完成不作为 PR 条件，也不得由 Agent 重新解释或改写工作台三桶数值（v1 L145–155）。

### 6.3 PR

- PR 经统一 `pr_candidates` 视图筛选后现算，遵守最新正式有效修订、独立完成、可比较工作组等规则；不存当前 PR 或其他统计结果作为事实源（PLAN.md 2026-09-08 收窄前「业务表设计」L227（历史来源）；现承载见第 6 章）。
- PR 仅使用正式有效记录最新修订中的可比较、独立完成工作组；排除草稿、待补全训练记录、作废、旧修订、热身组、回归期数据及人工辅助组（v1 L186–195；PLAN.md 2026-09-08 收窄前「业务表设计」L247（历史来源）；现承载见第 6 章）。
- 独立完成包含有人旁边保护但全程未接触、未发力帮助完成动作的情况（v1 L186–195）。
- 待补全训练记录经补全并由用户确认成为正式有效记录后自动参与 PR，无需另行确认“纳入 PR”；正式写入遵守既定草稿确认、版本检查及事务规则（v1 L125、L186–195；v1 L204）。
- 无计划关联的正式有效记录可贡献 PR，但不是执行度证据（v1 L186–195）。
- 同一动作、器械变式、负重记法分别比较；单位可以换算，单只哑铃重量与双只总重不能直接混比（v1 L186–195；PLAN.md 2026-09-08 收窄前「业务表设计」`training_sets` 职责行 L217（历史来源）；现承载见第 5 章）。
- 最高重量要求至少一次明确完成的次数；同重量最高次数按单组计算，不累计多组（v1 L186–195）。
- 自重、计时、反向辅助负重不套用“重量越大越好”的 PR，首版保留实际表现，不新增特殊 PR 算法（v1 L186–195；PRD §5.8）。
- 辅助组排除普通重量／次数 PR，不新增辅助 PR，也不自动拆算独立完成次数（v1 L131）。
- 杠铃、哑铃、史密斯机等动作变式分别统计 PR（PRD §5.8 L258）。
- 首版不计算估算 1RM，也不将“重量 × 次数”总和直接当作进步指标（PRD §5.8 L259）。

### 6.4 复盘生成与重算

- `reviews`：SQLite 内保存 Markdown 复盘正文、生成时统计依据快照及来源修订引用；重生成追加不覆盖，依据变化后标记已变更（PLAN.md 2026-09-08 收窄前「业务表设计」L218（历史来源）；现承载见第 6 章）。
- 当前统计依据最新有效事实现算，不以持久化结果为事实源；复盘生成时允许冻结当时数值与来源修订作为历史解释证据，不作为当前统计输入；当前统计现算不要求通过历史数值快照恢复当前结果（PLAN.md 2026-09-08 收窄前「业务表设计」L194、L228–229、L246（历史来源）；现承载见第 6 章）。
- 统计仅使用每次训练最新有效的确认版本；新增、更正或作废后重新计算受影响统计，显示数据更新时间，不重复计入旧修订（v1 L101；PRD §5.8 L261）。
- 更正或作废后的统计处理：历史数值重算；旧复盘文本不静默改写，其依据数据变化时标记已变更，允许重新生成（v1 L67、L102；PLAN.md 2026-09-08 收窄前「业务表设计」L229（历史来源）；现承载见第 6 章）。
- 图表和数值由确定性计算结果提供；Agent 负责解释表现、指出缺失信息并给出下一步建议；Agent 不得修改统计数值，也不得补充没有数据支持的因果关系（PRD §5.8 L255–257；v1「业务模块职责」）。
- 复盘仅在用户显式请求时生成（2026-09-12 拍 Q3=B，Stage 3 D6 不变）：独立显式端点创建一个 Agent Run（无定时器、无按周／自动触发）；后端先确定性冻结统计与来源修订，仅一条预算内模型流程写解释正文、不得改写或编造数值；校验通过后由 `ReviewStore` 在事务内追加 Markdown、快照与精确来源，来源修订竞态整体回滚；重生成追加不覆盖，旧正文保留，依据变化沿用 stale 规则。实现归 Stage 4 S4-08。
- 回归期统计排除：接回期训练标注为“回归期”，不进入常规“连续进步／处方目标符合情况”的对比口径，也不计入 PR 类统计；实际工作组仍展示，按接回安排单独计算完成情况，不混入常规训练对比；用户确认恢复常规计划内容所形成的新版本生效后，后续训练才恢复常规口径；既有回归期标记随训练历史保留，标记录错只能经历史更正确认修正；首版不展示合格组百分比（v1 L103–104；PRD §5.8 L264）。

## 验收标准（待实现验证）

1. 同一版本 W1 截至当前应训练 3 次，正式确认完成 2 次、漏练 1 次，另有额外训练 1 次：完成率为 2/3（66.7%）；事后补练不改变该漏练及分母（v1 L198）。
2. 计划版本从周四开始，W1 为该周四至下一周三，W2 从下一周四开始；新版本没有应训练次数时显示“暂无”，旧版本数据不迁移；真实补录或更正仍可更新旧版本统计（v1 L200）。
3. 无打卡的到期安排保留分母；同次安排无论反馈几次都最多贡献一次完成（PLAN.md 2026-09-08 收窄前「业务表设计」L245（历史来源）；现承载见第 6 章；v1 L201 完成贡献部分）。
4. 对目标 8–10 次：9 次为符合目标，6 次为未符合，待补全修订中的工作组缺次数记为待补全；工作台与复盘均显示“符合目标 1 组／未符合 1 组／待补全 1 组”，不另显示信息不足状态或百分比（v1 L202）。
5. 目标区间 8–10 次时，8、9、10 均可符合，7、11 不符合；模糊表达不被擅自转换（v1 L203）。
6. 一条待补全记录的工作组缺次数、但重量已确认：该工作组仍进入组级判定并记为待补全；整条待补全训练记录不进 PR，补全并确认正式有效后自动参与，不受复盘报告是否生成影响（v1 L204）。
7. 同动作及变式下，正式有效工作组 60kg 分别完成 8、10 次，同重量 PR 为 10 而非 18；更正或作废后按最新有效记录重算（v1 L205）。
8. 80kg 更正为 60kg 后 PR 不再使用 80kg；确认作废后不参与统计；受影响的旧复盘标记依据已变更（PLAN.md 2026-09-08 收窄前「业务表设计」L244（历史来源）；现承载见第 6 章；v1 L111）。
9. 深蹲先独立完成 100kg，一周后实际由他人帮助完成 110kg：PR 仍为 100kg；若用户确认仅旁边保护、全程不碰杠铃并独立完成，则满足其他条件时可更新为 110kg（v1 L207）。
10. 当前统计依据最新有效事实现算；复盘历史快照保留生成时数值与来源，重生成新增报告而不覆盖旧正文，历史快照不污染当前统计（PLAN.md 2026-09-08 收窄前「业务表设计」L246（历史来源）；现承载见第 6 章）。
