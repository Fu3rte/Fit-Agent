# 计划编排（workout-planning reference）

本文件是模型指令，只写 [planning-rules.md](planning-rules.md) 之外的编排口径。与
`app/domain/plans/schema.py`／`rules.py` 冲突时一律以源码为准；本文件不新增数值阈值。

## 频率与训练日

- 每周训练次数取自画像 `weekly_frequency` 的 `known` 值；`training_days` 数量必须等于该值（`PlanDraft`
  强制），日期落在 `starts_on` 起连续七天内且互不重复。
- 频率数字本身不决定分化：同一频率可以有多套成立的安排。训练日的职责按动作模式覆盖与恢复间隔分配，
  依据动作模式、恢复间隔与用户偏好选择，不套用固定分化模板名称。
- 主要动作模式按目标覆盖：膝主导、髋主导、水平推、水平拉、垂直推、垂直拉、核心／负重行走。目标决定
  覆盖的侧重，不决定模板名称。
- 覆盖顺序是优先项，不是必填项：某个模式在本次检索结果里没有可用候选时就不安排，在 `explanation` 说明
  未纳入；徒手画像下检索不到某一模式按此处理，不换成非徒手的目录动作顶替。
- 训练间隔按恢复需要安排，不为了凑模板把高疲劳模式排在一起。

## 训练变量

每个动作写清：职责、组数、次数区间、选重方式、休息、动作标准与替代。

- 组数与次数区间是可被后续训练记录推翻的起点，不引用固定次数表。
- 增肌目标下，约 10 组/肌群/周可作为证据锚点之一，不作为人人必须达到的固定下限。
- 不要求重量、次数与组数同时增加；不机械套用统一的每周总组数。
- 负荷值只照抄 `candidate_actions` 的 `starting_load`：`known` 时连同来源训练与组序号照抄，
  `needs_calibration` 时不给出任何具体重量。
- 处方类型必须与目录记录口径一致，自重与计时处方不带负荷字段。

## 未知与缺失

- 目标、训练方式或水平为 `unknown`／`denied` 时，相关选择按未知处理，在 `explanation` 写明假设，
  不补造事实。
- 目录未返回的动作不安排，也不换用名称相近的另一个动作顶替。
