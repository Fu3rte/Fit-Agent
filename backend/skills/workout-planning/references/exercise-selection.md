# 动作选择（workout-planning reference）

本文件是模型指令，补 [planning-rules.md](planning-rules.md) §2 之外的检索与选择细节。选择顺序的唯一
出处是 `planning-rules.md` §2，本文件不重复；与 `app/domain/plans/rules.py` 冲突时以源码为准。

## 检索覆盖

事实采集阶段先按目标与训练方式确定本次要覆盖的动作模式，再逐个模式检索。检索结果只用于确定 canonical
`exercise_id`：命中为空的模式说明目录缺少候选，换标准名、别名或器械词再检索一次，仍为空就不安排该类
动作，并在 `explanation` 说明本次未纳入。

## 候选动作的判断维度

比较同一层级的候选时看：动作模式、目标肌群、技术门槛、稳定性要求、局部疲劳、全身疲劳、学习成本、
器械可得性。这些是判断维度，不是 `Exercise` schema 的字段。

## P0—L3 起点

| 模式 | P0 优先候选 | 条件式候选 |
| --- | --- | --- |
| 膝主导 | 坐站、腿举、哈克深蹲、箱式杯式深蹲 | 轻杠铃深蹲学习 |
| 髋主导 | 臀推、腿弯举、绳索拉臀、垫高壶铃硬拉 | 轻哑铃 RDL |
| 水平推 | 器械推胸、上斜俯卧撑、稳定哑铃推 | 空杆卧推学习 |
| 水平拉 | 坐姿划船、胸托划船 | 轻哑铃单臂划船 |
| 垂直推 | 器械肩推、轻哑铃推举 | 空杆推举学习 |
| 垂直拉 | 高位下拉、辅助引体 | 标准引体学习 |
| 核心 | 死虫、Pallof、低负荷农夫走 | 更高难度抗伸展 |

表中的名称只作检索取向与先后比较，动作是否可用仍由目录 `recommendable`、记录口径与画像禁用项决定；
身份一律取本次检索返回的 canonical `exercise_id`。

P0 优先高稳定、易学习、容易调负荷的动作；L1 起可以引入自由重量；L2／L3 按目标决定专项性。

## 传统硬拉准入

传统硬拉不是计划的必选项。安排地面传统硬拉前确认：无痛髋铰链；轻负荷下可重复的躯干与杠铃路径；
合适的杠铃片与地面空间；用户有明确的硬拉力量、技术或专项目标；当周疲劳预算允许。

任一条不成立就不安排地面传统硬拉，用臀推、腿弯举、RDL、背伸或绳索拉臀训练后链。学习顺序：

```text
髋铰链练习 → 垫高壶铃硬拉 → 高把陷阱杠或轻 RDL → 地面传统硬拉
```

## 替代与回退

替代保持至少一项主要职责一致：动作模式、目标肌群、专项性或疲劳预算，不因器械排队随机换成无关动作。
为每个主要动作给出同场地替代与更低技术难度的回退，并写清进入更难版本的可观察标准：能稳定重复、动作
路径可控、不需要额外稳定条件。
