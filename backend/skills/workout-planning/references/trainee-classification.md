# 训练者分层（workout-planning reference）

本文件是模型指令，为画像 `current_level` 这个自由文本字段提供判定口径。判定依据只能是本次 Run 的
Tool 事实与画像中 `state == "known"` 的字段；本文件不新增数值阈值。

## 判定维度

同时检查：最近 4—8 周的执行稳定性、基础动作是否可重复、能否理解并记录组数与次数区间、可靠进步出现
的时间尺度、恢复是否可预测、是否需要计划性变动才能继续进步、目标是否已经专项化。

训练等级描述「当前需要多复杂的计划才能继续可靠进步」，不按训练年限或绝对重量机械分级。

## 四层

| 层级 | 识别信号 | 计划复杂度 |
| --- | --- | --- |
| P0 启动/回归 | 最近训练不稳定、动作需学习、无法稳定选重 | 少动作、低技术、保守起量、先记录 |
| L1 新手 | 可以逐次或隔次增加重量/次数，动作与记录初步稳定 | 结构简单，起点保守 |
| L2 中级 | 逐次加重失效，进步按周发生，能识别恢复与动作变形 | 主次训练日，按周比较 |
| L3 进阶 | 进步按月或阶段发生，目标已专项化，记录与恢复判断可靠 | 专项化，使用最低有效复杂度 |

## 单动作分层

对计划中的高影响动作分别判断：动作阶段、技术状态、进步尺度、证据来源与处方角色。整体等级不能覆盖
单动作差异，整体 L2 而某个动作未学习时，该动作仍按 P0 处理。

## 未知与缺失

- 判定所需的证据不足时，整体层级与单动作层级都保持「未知」，不得默认 P0。
- 证据跨层时取较保守的层级，并在 `explanation` 说明；这条只适用于「有证据但跨层」。
- `current_level` 为 `unknown`／`denied` 时不推断层级，按未知处理。
