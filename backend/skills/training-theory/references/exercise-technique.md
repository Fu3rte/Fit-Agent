# 动作技术与重量口径

本文件解释动作本身：模式差别、稳定性与疲劳代价、活动范围、技术要点，以及同一个重量数字在不同口径下
意味着什么。

## 动作模式与器械形式

- 动作模式决定练到哪个动作、哪块肌肉：膝主导、髋主导、水平推、水平拉、垂直推、垂直拉、核心与负重行走
  各有主要职责，模式之间不互相替代。
- 器械形式按目标、稳定性要求、偏好与疲劳成本选择。固定器械更容易稳定与调重，自由重量需要更多协调与
  控制；两者都能达成训练效果，器械形式本身不表示训练等级。
- 稳定性的代价不同：需要额外稳定的动作，同一肌群能用上的重量更低，局部与全身疲劳更高。这不是「更难」，
  只是代价不同。
- 活动范围：完整幅度增强力量，部分幅度没有优势（依据见 [sources.md](sources.md)）。幅度受关节条件、
  控制能力与器械结构限制时，先固定可重复的幅度，再谈加重。

## 技术要点

- 一般要点停在可观察的层面：动作路径是否稳定、同一幅度能否重复、是否需要额外稳定条件、下一组是否还能
  保持同样标准。
- 判断技术是否过关，用可重复性作标准：能稳定重复、路径可控、不需要额外稳定条件，才进入更难版本，见
  [exercise-selection.md](exercise-selection.md)。
- 疼痛与不适只讲一般执行要点与教育信息，并建议咨询专业医疗人员；不据疼痛部位推导禁用动作，也不给康复
  方案与进阶时程。用户转述「医生已允许恢复训练」时，按用户提供的事实复述。

## 重量口径的意思

同一个数字，在不同口径下指的是不同的东西：

| 口径 | 数字表示什么 |
| --- | --- |
| 单件器械值 | 单件器械的重量（例如单只哑铃） |
| 杠铃总重 | 含杠铃杆的总重量 |
| 配重器械显示值 | 器械配重刻度显示的值 |
| 加载片总重 | 加载片合计，不含器械空载自重 |
| 单侧值 | 一侧的重量 |
| 外加重量 | 额外加上的重量，自身体重不在此数内 |
| 辅助重量 | 辅助抵消的重量 |

- 负重动作的数字必须带口径才说得清；自重与计时动作没有负重可记，不存在「0kg」这种写法。
- 跨口径不做换算、不做比较：同一个数字在不同口径下含义不同，比较缺少依据。要比较就先统一口径。
- 口径以动作目录里该动作的记录为准，见 [progression.md](progression.md) 的示例。

## 示例：杠铃和哑铃的卧推

**用户问**：卧推的重量怎么算？杠铃和哑铃不一样吗？

**答法**：说明杠铃卧推按含杠铃杆的总重记录，哑铃卧推按单只手里的重量记录，同一个数字跨口径不可比较；
多条候选按器械与体位摆出让用户收敛，用户指明「平板杠铃」后只讲那一条的动作与口径；组次与个体重量留给
计划流程。

## 示例：名称相近的独立记录

**用户问**：引体要加多少重量？负重引体和引体是同一个动作吧？

**答法**：纠正前提——普通引体、负重引体、辅助引体在目录里是三条彼此独立的记录，成绩互不顶替；普通引体
只有次数可记，负重引体按外加重量记录，辅助引体按辅助重量记录；加多少属于个体安排，按真实训练记录决定。

## 示例：目录里没有的动作

**用户问**：我膝盖不太舒服，想练颈后推举，怎么做比较好？

**答法**：说明目录里没有「颈后推举」这个候选，可以换标准名或器械词再找一次，并说明那是换词后的新结果；
介绍其他候选时明确标注为名称与器械形式相近的另一个动作，各自口径独立；膝盖不适只给一般执行信息并建议
咨询专业医疗人员，不据伤病名称推导禁用动作。

## 替代与回退

替代要保持至少一项主要职责一致：动作模式、目标肌群、专项性或疲劳预算。为每个主要动作准备同场地的替代
与更低技术难度的回退，并写清进入更难版本的可观察标准。取舍顺序见
[exercise-selection.md](exercise-selection.md)。
