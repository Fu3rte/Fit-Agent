# 训练变量与常见安排结构

安排的名字不重要，它改了哪个变量才重要。评价任何一种练法，先回答「它动了什么」。

## 六个变量

| 变量 | 改它会发生什么 | 代价 |
| --- | --- | --- |
| 训练量（组数×次数） | 有剂量反应，但边际递减 | 量越大恢复负担越大；不存在统一上限 |
| 强度（重量、接近力竭的程度） | 力量对较重的重量有剂量反应；肌肉量在很宽的区间都能增长 | 越接近力竭，单次恢复成本越高 |
| 频率（每周几次） | 每周 2 次以上对力量有优势；总量相同时，频率高低对肌肉量差别很小 | 频率高占用日程，也更容易撞上恢复不足 |
| 密度（单位时间内做多少） | 省时间，提高单位时间的工作量 | 密度高会让后续组的质量下降 |
| 休息（组间、组内） | 影响下一组能完成多少 | 比较的口径不同，结论就不同；不能泛泛说休息长短无所谓 |
| 动作选择 | 决定练到哪个动作模式、哪块肌肉 | 换动作会让记录失去可比性 |

## 常见安排结构各改了什么

| 结构 | 做法 | 它改的变量 |
| --- | --- | --- |
| 常规组 | 固定组数次数，组间休息 | 量、强度、休息 |
| Rest-pause（短休后追加） | 一组做到接近极限，短休后再做几次 | 在疲劳背景下追加工作量 |
| Cluster（组内分段休息） | 把一组拆成几小段，段间短休 | 降低组内疲劳，保住动作速度 |
| EMOM（每分钟开始一组） | 固定时间窗口内完成规定次数 | 密度与恢复窗口 |
| 递减组 | 一组力竭后减重继续 | 在疲劳下追加量，代价高 |
| 金字塔 | 次数逐组递增再递减 | 各组努力程度的分配 |
| GTG（分散做少量） | 一天里多次、每次少量、不做到疲劳 | 频率与单次疲劳 |
| AMRAP（一组做到做不动） | 单次最大暴露 | 最接近测试形式，恢复代价最高 |

## 三条使用规则

1. **同总次数不等于同疲劳。** 都是 40 次，分成 5×8、分成短休追加、放进定时窗口，努力程度与恢复负担
   完全不同。比较练法时不能只比总次数。
2. **没有普遍更优的结构。** 有研究支持：不同组结构在力量与肌肉量上的差异小到可以忽略；差别主要体现
   在当次疲劳与动作速度上。选结构看代价，不看名气。
3. **周期化不是必需品。** 总量相同的情况下，周期化带来的优势很小，对肌肉量基本没有差异。安排是否需要
   分阶段，取决于用户能不能稳定执行与是否需要长期持续进步，不是越复杂越好。
