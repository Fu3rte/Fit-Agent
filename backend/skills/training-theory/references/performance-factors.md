# 什么在限制你的表现

用户说「卡住了」「练不动了」「进步慢」，先分清限制来自哪一类，再谈改什么。五类原因可以同时存在，
一次训练的表现下降不能直接指认是某一类。

## 五类原因

| 类别 | 用户能观察到的现象 | 改什么有用 |
| --- | --- | --- |
| 力量储备 | 同样的重量越做越吃力，加一点重量就掉次数 | 提高能做几次的那个重量本身 |
| 动作熟练与经济性 | 同一个动作晃、借力、节奏乱，做得多的那几次幅度缩水 | 降低难度练熟练度、固定动作标准 |
| 连续输出维持 | 一组前半段正常，后半段明显掉速度或掉次数 | 练连续输出本身（更长的一组、更接近力竭的组） |
| 组间恢复 | 第一组正常，后面几组明显衰减；休息久一点就好很多 | 改休息时长、改训练日密度、改一周安排 |
| 当天状态与测试条件 | 睡眠、体重、握法、动作幅度、当天疲劳不同，数字就不同 | 先固定测试条件，再比较数字 |

## 三层分开看

| 层 | 记什么 | 误用方式 |
| --- | --- | --- |
| 训练刺激 | 组数、次数、重量、休息、接近力竭的程度 | 把「练得多」当成「效果好」 |
| 即时反应 | 变慢的那一组、吃力程度、组间恢复后还能做多少 | 把一次训练的感受当成长期结论 |
| 长期适应 | 几周后同一标准下的终点数字 | 用一周的数据下结论 |

单次波动不构成趋势。判断进步要同一动作、同一标准、同一条件下的多次记录。

## 耐力类目标要降级承诺

目标是「一组能做更多次」时有个前提必须说清：在所有训练结局里，**肌肉耐力的证据基础最弱**。力量与
肌肉量各自有被确认有效的变量，耐力这一项目前没有任何训练变量被确认能稳定提高它。

因此：

- 可以给用户：终点怎么定义、怎么固定测试条件、观察哪几个数字、怎么安排一次单变量对照。
- 不能给用户：某种安排必然提高次数的承诺，或「专门练耐力」的特效方案。

## 停练之后

- 停练时间不超过此前训练时长时，已获得的收益大体维持；停得更久则消退。
- 复训时回升比初次练更快，前期回升最明显。
- 但「一次能做很多次」这类表现，与力量回升的速度不同，不能按力量的恢复速度推断它。
- 回归期先减量不加重量，是保守且可验证的做法；回到什么水平由同一标准下的测试确定，不预估周数。
