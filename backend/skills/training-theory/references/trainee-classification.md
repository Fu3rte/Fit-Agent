# 训练者与动作的分层

分层描述的是「当前需要多复杂的计划才能继续可靠进步」，不按训练年限或绝对重量机械分级。依据只能来自
画像里的经验描述、本次请求的说法与实际记录。

## 判定维度

同时检查：最近数周的执行稳定性、基础动作是否可重复、能否理解并记录组数与次数区间、可靠进步出现的时间
尺度、恢复是否可预测、是否需要计划性变动才能继续进步、目标是否已经专项化。

## 四层

| 层级 | 识别信号 | 计划复杂度 |
| --- | --- | --- |
| P0 启动/回归 | 最近训练不稳定、动作需学习、无法稳定选重 | 少动作、低技术、保守起量、先记录 |
| L1 新手 | 可以逐次或隔次增加重量/次数，动作与记录初步稳定 | 结构简单，起点保守 |
| L2 中级 | 逐次加重失效，进步按周发生，能识别恢复与动作变形 | 主次训练日，按周比较 |
| L3 进阶 | 进步按月或阶段发生，目标已专项化，记录与恢复判断可靠 | 专项化，使用最低有效复杂度 |

层级越高不等于计划越复杂越好：L3 的原则是使用能继续进步的最低有效复杂度。

## 单动作分层

对计划中的高影响动作分别判断：动作阶段、技术状态、进步尺度、证据来源与在计划里的角色。整体等级不能
覆盖单动作差异——整体 L2 而某个动作尚未学习时，该动作按 P0 处理。

## 未知与缺失

- 判定所需的证据不足时，整体层级与单动作层级都保持「未知」，不得默认 P0。P0 用于「有证据显示不稳定」，
  不是「没信息」的默认值。
- 证据跨层时取较保守的层级，并说明依据；这条只适用于「有证据但跨层」。
- 经验描述缺失或为空时不推断层级，按未知处理。

分层的用途在 [program-design.md](program-design.md) 与
[exercise-selection.md](exercise-selection.md)：层级决定起点动作、动作数量与进步尺度的期望，不决定具体
组次。
