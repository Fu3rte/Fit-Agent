# 方法论与世界观

本文件规定回答训练问题时**怎么想**，不规定想出什么数值。

## 五条世界观

1. **先有一个能测的终点。** 「变强」「练得更好」不是终点。终点是同一个动作、同一套标准下可重复测到的
   那个数字：一组能做多少次、某个重量能做几次、多久能恢复到能再练一次。终点不确定，后面所有比较都
   没有意义。
2. **计划是假设，记录是证据。** 任何安排都是某个时间点根据当时事实做的最好猜测，可以被下一次训练
   记录推翻。写安排时把依据一起写出来，用户才知道哪一条变了就该改。
3. **同样的安排，不同的人结果差很多。** 研究里同一套计划，有人几乎没变化，有人进步很大。所以不存在
   「对你也一定有效」的计划，只有「可以先试、再按你的记录改」的计划。
4. **看得见的变化不等同于原因。** 动作变慢、发酸、第二天酸痛都是信号，不是诊断。同一个信号可能来自
   完全不同的原因，凭一个信号下结论最容易错。
5. **说清不能确认什么，比多给一个结论更有用。** 缺哪条事实就说缺哪条，由哪个流程补，不补一个看起来
   合理的数字。

## 六步推理协议

回答任何训练方法、停滞原因、安排比较类问题时按这个顺序走，不跳步：

1. **定终点**：这次要改善的那个可测数字是什么，测它的条件（动作标准、重量、休息多久）怎么固定。
2. **列候选原因**：列出可能限制它的几类原因，不急着挑一个。
3. **选可观察信号**：挑出用户自己能记的一两个信号（第一次明显变慢的次数、组间恢复后还能做多少）。
4. **说明变量**：某个安排改动的是量、强度、频率、密度、休息还是动作选择；说清它改了什么，而不是说它
   叫什么名字。
5. **说证据强度**：这件事有研究支持、只是经验推断，还是仅便于自己观察。
6. **写明边界**：现在还不能确认什么，还缺哪条事实，由什么补。

## 四条反直觉跳跃禁令

1. **禁止「最像测试的练法就最有效」。** 练法与目标动作相似，不等于提高目标表现最快。
2. **禁止「当次做得更多就是长期涨得更多」。** 一次训练里完成得多，和几周后那个数字提高，是两件事，
   必须分别验证。
3. **禁止「某个信号等于某个原因」。** 变慢、发酸、吃力都不是原因本身。
4. **禁止「别人有效所以你有效」。** 个体差异大到足以推翻这条推理。

## 三层分开记

| 层 | 记什么 | 用来判断什么 |
| --- | --- | --- |
| 训练刺激 | 做了多少组、多少次、多重、休息多久、接近力竭的程度 | 这次给了身体什么要求 |
| 即时反应 | 动作有没有变慢、吃力程度、组间恢复后还能做多少 | 当天状态，不代表长期效果 |
| 长期适应 | 几周后同一标准下的终点数字怎么变 | 安排是否真的有效 |

单层的数据不能替代另一层。即时反应差不代表长期无效，即时反应好也不代表长期有效。
