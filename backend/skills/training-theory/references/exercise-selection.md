# 动作选择与替代

选择顺序用于在候选集合内排序，不改变可执行条件与安全前提。

## 检索覆盖

先按目标与执行条件确定本次要覆盖的动作模式，再逐个模式找候选：

- 命中为空说明目录里没有该模式的候选。换标准名、别名或器械词再找一次，每次如实说明这是新结果。
- 仍为空就不安排该类动作，并在说明里写清本次未纳入。
- 候选只用于确定动作身份：名称取目录里的记录，名称相近的动作是彼此独立的记录，见
  [exercise-technique.md](exercise-technique.md)。

## 候选动作的判断维度

比较同一层级的候选时看：动作模式、目标肌群、技术门槛、稳定性要求、局部疲劳、全身疲劳、学习成本、
器械可得性。这些是判断维度，按目录里该动作的器械、目标肌群与步骤核对，不把判断当成目录事实抄出去。

## 起点优先级

| 模式 | 优先候选 | 条件式候选 |
| --- | --- | --- |
| 膝主导 | 坐站、腿举、哈克深蹲、箱式杯式深蹲 | 轻杠铃深蹲学习 |
| 髋主导 | 臀推、腿弯举、绳索拉臀、垫高壶铃硬拉 | 轻哑铃 RDL |
| 水平推 | 器械推胸、上斜俯卧撑、稳定哑铃推 | 空杆卧推学习 |
| 水平拉 | 坐姿划船、胸托划船 | 轻哑铃单臂划船 |
| 垂直推 | 器械肩推、轻哑铃推举 | 空杆推举学习 |
| 垂直拉 | 高位下拉、辅助引体 | 标准引体学习 |
| 核心 | 死虫、Pallof、低负荷农夫走 | 更高难度抗伸展 |

表中的名称只作取向与先后比较，动作是否可用由本次可用器械与已保存的受限动作决定；身份取目录里的记录。
优先高稳定、易学习、容易调负荷的动作；经验增加后再引入自由重量与专项动作。

起点优先级与训练者层级配合使用，见 [trainee-classification.md](trainee-classification.md)。

## 传统硬拉准入

传统硬拉不是计划的必选项。安排地面传统硬拉前确认：无痛髋铰链；轻负荷下可重复的躯干与杠铃路径；
合适的杠铃片与地面空间；用户有明确的硬拉力量、技术或专项目标；当周疲劳预算允许。

任一条不成立就不安排地面传统硬拉，用臀推、腿弯举、RDL、背伸或绳索拉臀训练后链。学习顺序：

```text
髋铰链练习 → 垫高壶铃硬拉 → 高把陷阱杠或轻 RDL → 地面传统硬拉
```

## 替代与回退

- 替代保持至少一项主要职责一致：动作模式、目标肌群、专项性或疲劳预算。不因器械排队随机换成无关动作。
- 为每个主要动作给出同场地替代与更低技术难度的回退。
- 写清进入更难版本的可观察标准：能稳定重复、动作路径可控、不需要额外稳定条件。
- 换动作会让历史记录失去可比性：同一目标下频繁换动作，等于不断重置比较基线，见
  [training-variables.md](training-variables.md)。
