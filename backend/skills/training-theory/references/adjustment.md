# 停滞、变化与调整

调整由用户反馈或要求触发：时间变了、器械变了、某个动作不合适、或者就是感觉停滞了。本文件说明怎么
归因、改哪一项、怎么保守、怎么验证。

## 一、先分清变化的来源

| 观察到的变化 | 优先怀疑 | 对应的调整方向 |
| --- | --- | --- |
| 同样的重量越做越吃力 | 力量储备、恢复不足 | 先看恢复与频率，再谈加重 |
| 动作晃、借力变多、幅度缩水 | 动作熟练与技术状态 | 降难度练技术，先不加重量 |
| 前半段正常、后半段掉得快 | 连续输出维持 | 改组内结构或组长度 |
| 第一组正常、后面几组衰减明显 | 组间恢复、训练日密度 | 改休息时长或一周安排 |
| 数字不动但训练量涨了 | 练的内容与终点不匹配 | 让练习更贴近终点的测法 |
| 一段时间没练，回来后全面下降 | 停训消退 | 先减量回归，见第三节 |

五类限制原因的完整表见 [performance-factors.md](performance-factors.md)。一次训练的表现下降不能直接指认
是某一类，见 [diagnosis-and-experiment.md](diagnosis-and-experiment.md)。

## 二、可调整对象与需要的依据

| 调整对象 | 需要先明确 |
| --- | --- |
| 结构或频率 | 现有结构、目标与相关限制；动作详情可以继续为空 |
| 指定动作的组数 | 改的是哪个训练日的哪个位置 |
| 替换动作 | 目录里的事实、相关伤病与器械限制 |
| 按实际表现调整 | 相关逐组数据、重量口径与必要反馈 |

信息不充分时说明缺什么、由谁补，不替用户填。调整只索取完成本次任务必需的信息，其余保持未知。

## 三、一次只改一个主要变量

同一次调整里，一个动作只改重量、次数或组数中的一项。

**适用条件**：同一动作、同一口径、执行条件稳定（器械与动作标准不变），用户能连续记录若干次。

**理由**：同时改多个变量就无法判断是哪一项起了作用，等于没做对照。

**局限**：适用条件不成立时不适用——器械刚换、动作刚学、训练中断后刚回归，这时多个变量本来就需要同时
重设，这属于重建基线，不叫对照；这时把重建的目的讲清楚。此外单变量调整观察周期长，用户可能等不到结论；
这时说明代价，由用户决定。

结构调整可以同时涉及多个动作：换训练日职责、改动作顺序、替换动作本来就会牵动同一训练日的其他安排，这时
要说明牵连了哪些动作、为什么牵连。

## 四、复训

停练之后收益会部分回来、复训回升更快，这是对复训若干周后终末结果的观察，不能推出复训首日可以沿用停练前
的重量。依据见 [performance-factors.md](performance-factors.md) 与 [sources.md](sources.md)。

**做法**：复训先从当次能规范完成的负荷开始。降组数、降重量、缩短单次训练都是可选策略，也可以先按原重量
试一组再决定。选哪一种，按当下的事实定：

- 该动作当次能否按标准完成目标次数，动作路径是否失控、幅度是否明显缩水；
- 当次与次日的耐受情况，包括酸痛、不适与疼痛信号；
- 可执行条件是否变化：器械、场地、可支配时间；
- 历史记录的口径是否与本次一致，口径不同就不是同一个数字。

**理由**：历史重量是过去完成过的事实，当前能做到多少要由当前的表现判断。先定一个能规范完成的起点，才能
取得可比的基线记录，后面才有得比。

**局限**：疼痛、动作标准无法保持或明显不适时，停止该动作并降阶或换动作，不靠降量硬撑。停练时间越长，
收益消退越多，历史重量的参考价值越低。具体从多少开始、多久回到原水平，由本次表现与后续记录判断，并说明
不确定性，不预估周数。

## 五、变量取舍

同时有多项诉求时，按顺序取舍：

1. 可执行条件与安全前提：器械、时间、伤病限制不满足的选项直接排除。
2. 目标与动作模式：先保证终点需要覆盖的模式。
3. 当前能稳定重复的技术难度。
4. 刺激与疲劳的性价比：同一目标下选恢复代价更低的做法。
5. 历史上有效且没出问题的做法。

取舍结果要写清改了什么、为什么改、依据哪条事实。变量含义见 [training-variables.md](training-variables.md)。

## 六、验证方法

- 终点先定：同一动作、同一口径、同一动作标准下要改善的那个数字，测它的条件固定下来。
- 一次只改一项，其余尽量不动：动作标准、测试时间、当天状态、总休息时长。
- 观察够几次再判断：单次结果受当天状态影响太大。
- 记录要可比：缺失次数、缺失口径或动作对不上的那一次按不可比处理，见
  [progression.md](progression.md)。
- 结论分三层说：当次反应、几周后的终点变化、以及现在还不能确认什么，见
  [methodology.md](methodology.md)。

## 七、调整说明要写什么

计划级或训练日的说明里写清：修改位置、原值、新值、理由、实际训练依据（含所用记录的日期与相关逐组
表现）、必要的重量口径、不确定性，以及删除内容的说明。依据不足或部分动作未经目录核实时，同样写进
说明。

## 示例：改一个动作的组数

**用户要求**：上传的计划里，把深蹲从 5 组改成 3 组。

**做法**：只改这一项，其余动作、顺序、重量、休息与原有说明保留；说明里写清改动位置、原值 5、新值 3、
依据是用户本次明确要求；本次没有可用训练记录，负荷保持未知。

## 示例：记录很少时怎么调整

**用户要求**：根据最近的训练调整一下计划。

**做法**：先按可获取的记录数量说明依据。记录很少时说明不确定性，围绕本次调整收集必要信息；不编造记录，
不把其他日期或他人的数据当成本次事实。若调整依赖训练表现而目前没有记录，先向用户索取。

## 示例：用户补充了新事实

**用户要求**：我刚补录了昨天的训练，按最新的再来一版。

**做法**：重新读取训练事实，基于新事实重新整理完整方案，重新完整展示全部内容与所用依据，等待用户再次
确认；未采纳的旧提案不再沿用。
