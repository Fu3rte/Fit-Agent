# 渐进规则（strength-training reference）

本文件给出力量训练渐进与负荷来源的解释口径。判定权属于工具与模型校验：本文件只解释含义，不复算、不新增
业务阈值。具体数值依据本次需求与真实记录，并说明不确定性。

## 0. 渐进的依据

本节只讲理由，不定数值。

- **只比较同一种东西**：能长期比较的只有同一动作、同一重量口径下做出来的完成组。别人的数值、成绩指标与
  旧计划都不属于当前能力，不能拿来当起点。
- **单次波动不是趋势**：一次训练受睡眠、体重、当天状态影响很大。根据一次结果就改安排，等于拿噪声当信号。
- **一次只改一个变量**：同时改重量、次数与组数，事后无法判断是哪一项起了作用，也就没有可归因的对照。
- **数据不足先补记录**：没有可比记录时先取得一份同标准下的记录，再由记录决定，不凭感觉造一个中间值。
- **个体差异很大**：同一套安排下不同人的变化幅度可以差很多，规则只处理「这个人的记录说了什么」。

## 1. 事实优先级与数据不足

```text
本次 Run 的 Tool 事实（画像字段、当前计划、训练记录、目录事实）→ 不推断、不补默认值
```

- 可沿用的负荷来源有：已核实训练记录里同动作、同口径的逐组 `weight_kg` 与 `load_convention`，以及当前计划
  里的计划值；计划值是安排，实际完成记录优先。成绩指标不构成加重依据。
- 目标组记录不完整、次数缺失或动作不匹配时视为该次训练不可比。
- 数据不足时只写「待校准」或「未知」，不给任何具体重量。

## 2. 可比记录

比较两次训练前，至少保持动作、动作标准、器械与重量口径一致：

- 动作身份取自目录 canonical `id`，不做同义合并。
- 重量口径取自目录 `load_convention`，跨口径不做换算与比较。
- 组顺序与组内容以实际记录为准，单次结果只作线索。

## 3. 渐进思路

- 进步来自稳定执行与逐步增加的刺激，恢复能力要能跟上。
- 提高重量、提高次数与增加组数是不同的变量，改变时说明改的是哪一个、代价是什么。
- 是否提高强度由后续真实记录决定，不由本层给出固定次数、阈值或加减重规则。
- 停练后回归先降量、不动重量是可用记录验证的保守做法；回到什么水平由同一标准下的记录确定。

## 4. 负荷来源

- 负荷只来自本次 Tool 事实：已核实训练记录里的逐组 `weight_kg` 与 `load_convention`、当前计划里的计划值，
  或用户本次明确给出的值。计划值与实际完成事实区分，采用实际记录时说明依据与不确定性。
- 重量有值（包括 0）必须明确 `load_convention`；未知保持 null。
- 本层不提供个体起始负荷，也不把估算 1RM 与训练容量当作负荷来源。

## 5. 边界

不计算 PB、趋势与完成率；不做医疗判断；不把 RIR／RPE 写成处方刻度；不输出百分比减量与固定训练量表。
